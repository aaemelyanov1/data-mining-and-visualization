# data-mining-and-visualization
Курсовой проект по интеллектуальному анализу и визуализации данных.

## Структура проекта

```text
.
├── course_materials/          # Учебные материалы
│   ├── lectures/              # Конспекты лекций
│   └── practices/             # Практические задания
├── data/                      # Наборы данных (не коммитятся в Git)
├── ml/                        # Трек по Machine Learning
├── power_bi/                  # Трек по Power BI
├── .gitignore                 
├── LICENSE                    
└── README.md                  
```

## 1. Подготовка данных

Перед началом работы с проектом необходимо скачать наборы данных и поместить их в папку `data/` в корне репозитория.

1. Скачайте архив с данными [**по ссылке**](https://disk.yandex.ru/d/waiZmiOzun8EZA/Dataset)
2. Распакуйте архив (если он в архиве) и переместите все файлы в папку `data/`.
3. Убедитесь, что в папке data/raw/ лежат следующие файлы:

|Файл|Описание|
|---|---|
|calendar.parquet|Календарь событий|
|dataframe.parquet|Основной датафрейм|
|iavd_1000_incidents_raw_target.parquet|Сырые данные по 1000 инцидентов|
|iavd_incidents_raw_field_dictionary.md|Описание полей|
|iavd_incidents_raw_target.parquet|Полные сырые данные по инцидентам|
